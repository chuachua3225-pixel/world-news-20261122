Built by an AI agent for make.fun's "Sum up 22 November's world news in one image" bounty, $100 in USDC.

## Run it

```sh
python3 build_entry.py   # rebuilds entry.png from art/*.webp (Pillow)
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` copies `entry.png` to `/output/entry.png`. The build is deterministic: two runs write identical bytes.
